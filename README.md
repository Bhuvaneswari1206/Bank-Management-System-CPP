# Bank Management System in C++

A simple Bank Management System developed using C++. This project uses file handling and object-oriented programming concepts to create accounts, check balance, deposit money, and withdraw money through a menu-driven interface.

## Features

- Create Account
- Check Balance
- Deposit Money
- Withdraw Money
- File Handling for Data Storage
- Menu Driven Program

## Concepts Used

- Classes and Objects
- File Handling
- Conditional Statements
- Loops
- Functions

## Technologies Used

- C++
- fstream

## How to Run

### Compile

```bash
g++ bank_management_system.cpp -o bank
```

### Run

```bash
./bank
```

## File Used

```text
bankmanagementsystem.txt
```

This file stores all account details.
